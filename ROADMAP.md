## Главные тесты 2.5.0
- «Новый объект ... Октябрьская 16 ... Екатерина ... кухня 50 тысяч» → новый объект, а не Архангельская.
- «По Леонова удали тестовую работу» → точный `delete_work` или уточнение.
- «Плинтуса 31,8 метра по 800» → `update_work`, а не новая строка.
- Несколько действий одной фразой → один пакет preview → одно подтверждение.
- Undo последнего AI Brain-пакета.
- При выключенном ноутбуке FRAME не должен молча угадывать сложную команду локальным parser-ом.

## 2.5.x · укрепление Brain
- Добавить read-only запросы к базе: «сколько мне должны?», «что сегодня делать?», «сколько заработал за август?».
- Добавить resolver/validation для неоднозначных адресов и похожих работ.
- Отдельные правила для комиссий посреднику и third-party событий с user revenue = 0.
- Улучшить человекочитаемый preview до «было → станет».
- Добавить telemetry только локального качества: исходная фраза / draft / подтвердил или исправил.

## Переезд на OpenAI
- PWA не меняется: тот же `/analyze`, тот же JSON action schema.
- На FRAME AI Server меняется provider `ollama` → `openai`.
- OpenAI API key хранится только на сервере/в окружении, никогда в GitHub Pages.
- Использовать Structured Outputs, `store:false`, валидировать каждый action до записи.
- После стабильности можно перенести AI Server с ноутбука на постоянный backend.

## Синхронизация данных
- Следующий крупный слой после AI Brain: общая backend-база и синхронизация между iPhone/ПК.
- GitHub остаётся местом кода/релизов, а не пользовательских рабочих данных.
- IndexedDB может оставаться offline-cache и полевой резервной копией.
