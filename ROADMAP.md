# FRAME ROADMAP

## Сейчас: FRAME 2.4.0 · AI Inbox Beta
- Поставить обновление через GitHub Pages и проверить, что FRAME 2.3.0 данные сохранились.
- Открыть AI из конкретного заказа и проверить, что выбран правильный объект.
- Прогнать в живом FRAME команды: оплата, новая работа, покупка, расход посреднику, завершение работы.
- Проверить отмену последнего AI-изменения.
- На iPhone проверить браузерную кнопку диктовки. Если SpeechRecognition недоступен, проверить системную диктовку клавиатуры.
- В течение реальной работы собирать фразы, которыми пользователь естественно описывает события, а не придумывать «команды для программы».

## Следующий релиз AI
- Поддержать несколько событий в одной фразе: «получил 30 тысяч, 18 ушло на насос, завтра подключаем раковину».
- Добавить вопросы к базе без изменения данных: «сколько мне должны по Леонова?», «какие активные объекты?», «сколько заработал за август?».
- Добавить уверенность (`confidence`) и причину уточнения.
- Сделать умный выбор объекта/заказа надёжнее.
- Добавить подтверждение только для рискованных/неоднозначных действий; простые команды впоследствии смогут применяться одним тапом.

## Настоящий LLM
- Вынести AI-gateway на backend/serverless.
- Не хранить API-ключи в клиентском коде.
- Формализовать JSON schema для действий FRAME.
- Валидировать каждый ответ модели до применения.
- Разрешить модели только белый список операций: read/query/create/update, без произвольного выполнения кода.
- Добавить журнал: фраза → LLM-result → validation → DB mutation → undo metadata.

## Product
- FRAME Renovation остаётся первой вертикалью и полигоном.
- После устойчивой полевой эксплуатации выделить общий FRAME Core.
- Только после этого делать вертикали Marine / Auto / Service, переиспользуя ядро клиента, объекта, заказа, фото, работ, денег и AI-ввода.

## Параллельно
- Продолжить полевой тест финансов и прогресса по Леонова / Архангельской.
- Сохранить отдельную линию обучения remote construction takeoff как возможный дистанционный доход, не смешивая её с продуктовым roadmap FRAME.
