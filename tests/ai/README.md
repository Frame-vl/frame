# FRAME AI Test Suite

Автоматические регрессионные тесты для AI Brain.

Цель: ловить очевидные тупники до ручного теста на телефоне.

Сейчас проверяются:
- удержание текущего объекта в длинном разговоре;
- фразы «по этому объекту» и «учитывая вышесказанное»;
- явное переключение на другой объект;
- приоритет свежих фактов разговора над старым прогрессом;
- отличие обычного вопроса от изменения данных;
- создание `add_work` с количеством, ценой и итогом.

## Запуск

Тесты обращаются к FRAME AI Server по `/analyze`.

По умолчанию используется:

`http://127.0.0.1:8787`

Можно задать адрес и токен переменными окружения:

Windows PowerShell:

```powershell
$env:FRAME_AI_URL="http://127.0.0.1:8787"
$env:FRAME_AI_TOKEN="<FRAME AI token>"
python tests/ai/runner.py
```

Токен нельзя сохранять в репозитории.

Успешный релиз AI считается безопаснее, если весь набор проходит 100%. Новые реальные баги добавляются как отдельные сценарии в `scenarios.json`.
