FRAME 2.0.1 Field

Точечное обновление интерфейса и текущих данных поверх FRAME 2.0.0 Field.

Что изменено:
- исправлен live-preview серийной камеры на iPhone;
- в прайс-листе длинная кнопка «Закрыть» заменена компактным крестиком;
- главная очищена: история объектов убрана, показатели «Объекты», «В работе» и «Стоимость работ» стали входами в детализацию;
- добавлен общий раздел «Документы» с поиском, фильтрами и созданием документа через выбор объекта/заказа;
- документы можно удалять из истории без удаления объекта и расчётов;
- расходы по заказу разделены, включая «Материалы в цене под ключ»;
- к расходам и возмещаемым покупкам можно прикреплять фото чеков;
- добавлен универсальный раздел «Работы»;
- добавлены текущие реальные позиции в «Мои цены»;
- безопасно добавляются текущие карточки: детейлинг 5-я Матросская 26, Веселковая 12Б; в существующий объект Леонова 54 добавляется отдельный заказ «Сборка кухни».

Существующие объекты, платежи, фотографии и документы не очищаются. IndexedDB остаётся FRAME_DB, версия 2.

Публикация: загрузить содержимое архива в корень ветки main GitHub Pages с заменой существующих файлов. После успешного Pages deployment открыть на iPhone refresh.html опубликованного FRAME.
