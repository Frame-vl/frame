FRAME 2.5.1 · AI Brain Network Hotfix
=============================

Что изменилось
--------------
FRAME 2.4 доказал полевой цикл «сказал -> разобрал -> preview -> применил -> запись в базе».
2.5 перестаёт выращивать длинный список ручных языковых правил и подключает настоящий LLM-мозг через отдельный безопасный сервер.

Схема сейчас:
FRAME на iPhone -> FRAME AI Server на ноутбуке -> Ollama -> локальная LLM -> structured actions -> preview -> FRAME_DB

Схема потом:
FRAME -> тот же FRAME AI Server -> OpenAI Responses API -> те же structured actions -> FRAME_DB

Что умеет AI Brain draft
------------------------
- создать новый объект;
- создать новый заказ;
- изменить объект/заказ;
- добавить / удалить / изменить работу;
- поменять прогресс;
- добавить оплату;
- добавить расход/комиссию;
- добавить покупку;
- добавить заметку;
- вернуть несколько действий из одной разговорной фразы.

Важно
------
AI не пишет в IndexedDB напрямую. Модель только предлагает белый список structured actions.
FRAME показывает план, валидирует ссылки на object/order/work IDs и только после подтверждения применяет изменения.
Удаление требует отдельного подтверждения.

Безопасность
------------
- API/AI secret не хранится в GitHub Pages;
- URL и access token локального AI Server хранятся только на устройстве;
- IndexedDB остаётся FRAME_DB, DB_VERSION=2;
- полные фото/документы в AI Brain 2.5 не отправляются;
- OpenAI provider предусмотрен только на server-side и не активируется без отдельного API key.

Обновление GitHub Pages
-----------------------
1. Распаковать архив FRAME-2.5.0-AI-Brain.zip.
2. Загрузить содержимое архива в корень репозитория frame поверх текущих файлов.
3. Commit directly to main.
4. Открыть на iPhone:
   https://frame-vl.github.io/frame/refresh.html

Локальный мозг
--------------
FRAME AI Server поставляется отдельным архивом FRAME-AI-Server-0.1.0.zip.
Подробности: README_FIRST.txt внутри серверного архива.

Первый regression-test
----------------------
Фраза:
«Новый объект: Владивосток, Октябрьская 16, квартира 28. Заказчик Екатерина. Монтаж кухни 50 тысяч.»

Ожидается preview из двух действий:
1. Создать новый объект Октябрьская 16, кв. 28 / Екатерина.
2. Добавить в его первый заказ «Монтаж кухни» 50 000 ₽.

Ни Архангельская, ни другой текущий объект не должны быть изменены.
