ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Перед обновлением при желании сделайте резервную копию в FRAME → Настройки → Резервная копия.
2. Распакуйте архив.
3. Загрузите в корень репозитория всё содержимое архива, заменив старые файлы.
4. Сообщение коммита: FRAME 2.0.0 update
5. Выполните commit в ветку main.
6. Дождитесь зелёной галочки GitHub Pages.
7. На iPhone один раз откройте /refresh.html, затем основную страницу FRAME.

ВАЖНО О ДАННЫХ
- Не удаляйте данные сайта Safari.
- Не очищайте хранилище PWA вручную.
- refresh.html удаляет только Service Worker и файловые кэши.
- IndexedDB и localStorage с объектами, ценами и настройками не очищаются.
- Версия IndexedDB остаётся 2, object store `objects` не пересоздаётся.

КОНТРОЛЬ ПОСЛЕ ПУБЛИКАЦИИ
- В шапке указано 2.0.0.
- Откройте старый объект и убедитесь, что работы, оплаты, покупки и фото доступны.
- Измените комментарий старой работы и нажмите «Назад»: FRAME должен спросить, сохранять ли изменения.
- В заказе задайте договорную цену ниже расчётной: должна появиться «Индивидуальная скидка».
- Проверьте, что «Осталось» считается от договорной, а не от расчётной цены.
- На карточке объекта переключите «Показывать скидку в документах» и сравните КП в двух режимах.
- Откройте предпросмотр КП на iPhone: Кол., Ед., Цена и Сумма должны читаться горизонтально, без вертикальной россыпи цифр.
- В Фото нажмите «Снять серию»: камера должна оставаться открытой после снимка и добавлять всю серию одной кнопкой.
- В расходах смените «Оплата работнику» на «Прочие расходы по объекту»: поля работника и работы должны исчезнуть и очиститься.
