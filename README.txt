FRAME 2.4.1 Safari Voice Diagnostics

FRAME 2.4.0 AI Inbox Beta

Первый рабочий слой разговорного управления FRAME поверх стабильной архитектуры 2.3.0.

Что появилось:
- на главной: карточка «FRAME AI · BETA»;
- внутри каждого заказа: кнопка «✦ AI», которая сразу открывает AI с выбранным заказом;
- текстовое поле обычной человеческой команды;
- голосовой ввод через SpeechRecognition / webkitSpeechRecognition, если браузер его поддерживает;
- на iPhone при отсутствии браузерного SpeechRecognition можно использовать обычную диктовку клавиатуры в поле ввода;
- предпросмотр: тип действия, сумма/работа и целевой заказ до записи;
- журнал AI-действий;
- отмена последнего AI-изменения.

Первые поддерживаемые фразы:
- «Получил от заказчика 20 тысяч» → добавление оплаты;
- «По Леонова получил 15 500 рублей» → попытка выбрать Леонова и добавить оплату;
- «Добавь монтаж подсветки 3500» → новая работа;
- «Добавь монтаж плинтуса 33,6 метра по 800» → новая работа с количеством и ставкой;
- «Купил клей за 4000» → покупка мастера со статусом «К возмещению»;
- «Отдал посреднику 7000» → невозмещаемый расход по заказу;
- «Закончил плинтус» → поиск существующей позиции и прогресс 100%;
- «Запиши: клиент просит вернуться к кухне в пятницу» → заметка к заказу.

Важно про AI:
- в 2.4.0 нет внешнего LLM/API;
- разбор первой группы команд выполняется локально в браузере;
- текст не отправляется стороннему AI-сервису;
- API-ключи в код приложения не вшиваются;
- это фундамент будущего FRAME AI, а не попытка выдать набор регулярных выражений за полноценную языковую модель.

Почему так:
Сначала проверяем правильный UX: «рассказал → увидел, что FRAME понял → применил → данные появились в карточке». После полевого теста подключается настоящий LLM через backend, который будет возвращать структурированный JSON-действие, а не напрямую редактировать базу.

Безопасность данных:
- IndexedDB: FRAME_DB
- DB_VERSION: 2
- разрушающей миграции нет;
- AI-журнал: localStorage frameAiLogV240;
- AI-журнал включается в JSON backup;
- существующие объекты, оплаты, фото, документы и патчи 2.3.0 сохраняются.

Как обновить через GitHub Pages:
1. Распаковать архив FRAME-2.4.0-AI-Inbox-Beta.zip.
2. Загрузить всё содержимое архива в корень репозитория frame поверх текущих файлов.
3. Commit directly to main.
4. Дождаться GitHub Pages build/deployment.
5. На iPhone открыть: https://frame-vl.github.io/frame/refresh.html
6. После обновления на главной должна появиться карточка FRAME AI.

Первый полевой тест:
1. Открыть конкретный заказ, например Леонова.
2. Нажать «✦ AI».
3. Сказать/ввести тестовую команду.
4. Проверить целевой заказ и предпросмотр.
5. Нажать «Применить».
6. Вернуться в заказ и убедиться, что изменение реально появилось.
7. Для теста отмены вернуться в FRAME AI и нажать «Отменить последнее».
