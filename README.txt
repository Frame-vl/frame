FRAME 1.8.0 Field

Установка на GitHub Pages
1. В FRAME откройте Настройки → Резервная копия и сохраните файл.
2. Распакуйте ZIP.
3. Загрузите СОДЕРЖИМОЕ папки в корень репозитория: index.html, app.js, styles.css, sw.js, refresh.html, manifest.webmanifest, папку icons и текстовые файлы.
4. Дождитесь зелёного deployment.
5. Один раз откройте /refresh.html.

Важно
- refresh.html удаляет только Service Worker и кэш файлов приложения.
- IndexedDB, объекты, заказы, цены и localStorage не очищаются.
- Данные FRAME 1.7.0 автоматически подхватываются новой версией.
- Паспортные данные остаются необязательными и не попадают в резервную копию без отдельного согласия.

Главное в 1.8.0
- исправлены самопроизвольный зум, выезжающее поле даты и горизонтальное движение страницы;

- расходы по заказу и общая финансовая статистика за выбранный период;
- обновлённый фирменный прайс-лист;
- резервная копия включает новые данные.
