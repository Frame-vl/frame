FRAME 2.2.0 Modules & Order Ledger

Локальное PWA-приложение FRAME для строительных заказов, расчётов, полевого прогресса, расходов, оплат, фото и документов.

Что нового в 2.2.0:
- Объект является контейнером, а каждый заказ имеет собственные деньги и историю.
- Оплата одного заказа не уменьшает остаток другого заказа на том же адресе.
- «К возмещению» нажимается напрямую и открывает покупки конкретного заказа.
- Работы организованы по модулям. На карточке заказа одна компактная кнопка «Разделы работ» вместо длинного набора пустых модулей.
- Внутри модуля остаётся быстрый чек-лист: тап = 100%, долгое нажатие = частично, шаг 5%.
- «К закрытию» показывает только новый объём после предыдущего закрытия.
- Последнее закрытие можно отменить, пока по нему нет оплаты и сформированного документа.
- Перечень и акт по закрытию используют реальные объёмы, единицы и ставки, а не «1 этап».
- PDF-таблица получила более устойчивые денежные колонки и компактный формат рублей.

Архангельская, 21:
- Специальный тестовый заказ прогресса при первом запуске 2.2.0 пересоздаётся чистым, с 0% по всем работам.
- Сбрасываются только тестовые данные заказа прогресса Архангельской из 2.1.0. Остальные объекты и заказы не удаляются.
- Контрольный текущий набор должен дать 129 040 ₽ к закрытию, если поддон выставить на 60%.
- После закрытия 129 040 ₽ увеличение поддона с 60% до 100% должно дать новые 10 000 ₽.

Как обновить:
1. Распаковать архив.
2. Загрузить всё содержимое архива в корень GitHub Pages репозитория поверх текущих файлов.
3. Сделать commit в main.
4. Дождаться зелёного Pages build and deployment.
5. На iPhone открыть:
   https://frame-vl.github.io/frame/refresh.html
6. После обновления открыть FRAME и проверить Архангельская, 21 → заказ «Ремонт квартиры · прогресс работ» → «Разделы работ».

Хранилище:
- IndexedDB: FRAME_DB
- DB_VERSION: 2
- Разрушающей миграции нет.
- Обычные объекты, заказы, расходы, оплаты, фото и история документов сохраняются.
