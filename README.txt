ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Распакуйте архив.
2. Загрузите в корень репозитория всё содержимое архива, заменив старые файлы.
3. Сообщение коммита: FRAME 1.9.0 update
4. Выполните commit в ветку main.
5. Дождитесь зелёной галочки GitHub Pages.
6. На iPhone откройте /refresh.html один раз, затем основную страницу приложения.

ВАЖНО О ДАННЫХ
- Не удаляйте данные сайта Safari.
- Не очищайте хранилище приложения вручную.
- refresh.html очищает только кэш файлов и регистрацию Service Worker.
- IndexedDB и localStorage с объектами, ценами и настройками не затрагиваются.

КОНТРОЛЬ ПОСЛЕ ПУБЛИКАЦИИ
- Версия в шапке: 1.9.0.
- Настройки → Мои данные: экран не двигается влево и вправо.
- Поле даты не выходит за границы карточки.
- Мои цены → Полы: видны Линолеум и Ковролин.
- Новый заказ открывается у блока «Что делаем?».
- В заказе отдельно видны «Что делаем?» и «По заказу».
