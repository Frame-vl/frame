FRAME 2.0.2 Clean UX

Локальное PWA-приложение для заказов, расчётов, расходов, оплат, фото и документов мастера.

Как обновить:
1. Загрузить содержимое этого архива в корень GitHub Pages репозитория поверх текущих файлов.
2. Commit directly to main.
3. Дождаться зелёного pages build and deployment.
4. На iPhone открыть:
   https://frame-vl.github.io/frame/refresh.html
5. После обновления закрыть FRAME из переключателя приложений и открыть снова.

Хранилище:
- IndexedDB: FRAME_DB
- DB_VERSION: 2
- Существующие объекты, заказы, оплаты, расходы, фото и документы не пересоздаются.

Важное UX-правило:
Если FRAME показывает конкретный заказ, строка заказа должна быть кликабельной и вести в его карточку.
