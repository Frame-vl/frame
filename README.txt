FRAME 1.7.0 Field

Установка на GitHub Pages
1. Распакуйте ZIP.
2. Загрузите СОДЕРЖИМОЕ папки в корень репозитория: index.html, app.js, styles.css, sw.js, refresh.html, manifest.webmanifest, папку icons и текстовые файлы.
3. После зелёного deployment один раз откройте /refresh.html.

Важно
- refresh.html удаляет только Service Worker и кэш файлов приложения.
- IndexedDB, объекты, заказы и localStorage не очищаются.
- Перед обновлением полезно сделать резервную копию в Настройки → Резервная копия.

Главное в 1.7.0
- объект теперь хранит независимые заказы;
- карточки показывают работы, оплачено и остаток, без материалов в доходе;
- пошаговый модуль полов без полотна из десятков открытых блоков;
- одна кнопка добавления дверной работы: установка, обслуживание, проём;
- исправлен ввод десятичных значений через точку и запятую;
- поля не перерисовываются на каждом символе, клавиатура и курсор сохраняются;
- платежи без обязательных этапов, новый платёж предлагает остаток;
- покупки мастера со статусом «к возмещению / возмещено»;
- настройки ⚙︎: Мои данные, Мои цены, резервная копия;
- подробные цены по материалам и рисункам укладки;
- прайс-лист PDF с выбранными разделами, преимуществами и честной оговоркой;
- договор с заполненными или пустыми данными мастера;
- акт с пустыми реквизитами заказчика и местом для подписей;
- печатный A4-режим без тяжёлых тёмных заливок;
- безопасная миграция данных из 1.4–1.6.
