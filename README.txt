FRAME 2.1.0 Progress Closures

Локальное PWA-приложение FRAME для заказов, расчётов, расходов, оплат, фото, документов и полевого прогресса работ.

Что нового в 2.1.0:
- В карточке заказа раздел «Работы» теперь работает как чек-лист.
- Обычный тап по работе = 100% выполнено.
- Долгое нажатие = меню полного, частичного или сброшенного прогресса.
- Частичный прогресс задаётся ползунком 0–100% с шагом 5%; сумма пересчитывается на экране сразу.
- «К закрытию» считает только новый выполненный объём после прошлых закрытий.
- «Закрыть объём» создаёт неизменяемый снимок работ и обнуляет только новый объём к следующему закрытию; общий прогресс остаётся.
- К закрытию можно привязать оплату и сформировать «Перечень» или «Акт» из зафиксированного снимка.
- После первого закрытия цена и объём строки блокируются, чтобы старые документы не расходились с текущими данными.
- Для теста добавляется отдельный заказ «Ремонт квартиры · прогресс работ» на объекте Архангельская, 21. Все отметки изначально 0%.

Как обновить:
1. Распаковать архив и загрузить его содержимое в корень GitHub Pages репозитория поверх текущих файлов.
2. Commit directly to main.
3. Дождаться зелёного Pages build and deployment.
4. На iPhone открыть:
   https://frame-vl.github.io/frame/refresh.html
5. После обновления открыть FRAME и зайти: Архангельская, 21 → «Ремонт квартиры · прогресс работ» → «Работы».

Хранилище:
- IndexedDB: FRAME_DB
- DB_VERSION: 2
- Разрушающей миграции нет. Существующие объекты, заказы, оплаты, расходы, фото и документы сохраняются.

Тест Архангельской:
Если отметить текущий фактический объём, включая поддон на 60%, «К закрытию» должен дать 129 040 ₽.
