FRAME 2.3.0 Current Data Refresh

Контрольное обновление актуальных карточек FRAME на 25.08.2026 поверх архитектуры 2.2.0.

Что обновлено:
- цель чистого дохода на месяц: 300 000 ₽;
- покупки по чекам с датой до 25.08.2026 включительно переведены в «Возмещено»;
- Леонова, 34, секция 6, кв. 204: старый SPC-заказ сохранён отдельно, текущий пакет допработ обновлён до 168 380 ₽;
- по текущему пакету зафиксировано 100 000 ₽ фактической оплаты и 68 380 ₽ остатка;
- 13 000 ₽ доли посредника учтены расходами заказа, поэтому ожидаемая доля пользователя = 155 380 ₽;
- плинтус обновлён до предварительных 33,6 м.п. × 800 ₽;
- добавлен монтаж LED-подсветки кухни 3 500 ₽;
- Архангельская, 21: кондиционер отмечен как сторонняя работа 22–23.08.2026 с доходом 0 ₽;
- остальные объёмы Архангельской не меняются.

Безопасность данных:
- IndexedDB: FRAME_DB
- DB_VERSION: 2
- разрушающей миграции нет;
- одноразовый патч: frameCurrent230DataPatch;
- старые заказы, документы, фото и история оплат сохраняются.

Как обновить:
1. Распаковать архив.
2. Загрузить всё содержимое архива в корень GitHub Pages репозитория поверх текущих файлов.
3. Сделать commit в main.
4. Дождаться Pages build and deployment.
5. На iPhone открыть https://frame-vl.github.io/frame/refresh.html
6. После открытия FRAME проверить главную карточку цели, Леонова 34 и Архангельскую 21.
