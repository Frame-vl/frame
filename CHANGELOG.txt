FRAME 2.5.0 AI Brain Bridge · 25.08.2026

Главное:
- FRAME перешёл от наращивания regex-команд к сменному AI Brain provider-слою.
- Добавлено подключение к собственному FRAME AI Server по HTTPS URL + access token.
- При настроенном сервере команда отправляется локальной LLM через Ollama; без сервера остаётся ограниченный parser 2.4.x.
- AI Brain возвращает structured actions, а не свободный текст. Поддержаны create/update объекта и заказа, add/delete/update работы, прогресс, оплата, расход, покупка, заметка.
- Одна фраза может вернуть несколько действий. FRAME показывает единый план перед записью.
- Ключевой кейс «Новый объект ...» больше не должен автоматически попадать в выбранный существующий объект: локальный parser блокирует такое угадывание, а LLM получает отдельное правило create_object.
- Удаление работы требует danger-preview и дополнительного confirm.
- Для AI Brain добавлен batch undo на обратных операциях без сохранения полных фото-снимков объекта в localStorage.
- Адрес сервера и ключ подключения не зашиваются в GitHub Pages.
- FRAME_DB / DB_VERSION=2 сохранены, разрушающей миграции нет.
- Подготовлен отдельный FRAME AI Server 0.1.0: Ollama сейчас, OpenAI provider позже без изменения PWA action schema.
